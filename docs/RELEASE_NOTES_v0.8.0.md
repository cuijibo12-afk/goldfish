# Goldfish Memory v0.8.0

DSH可按需调用的本地长期记忆插件。插件/后端0.8.0，SQLite schema6；DSH使用用户自己的主模型，不绑定某个供应商，不需要金鱼独立LLM、Ollama或向量服务。

## 主要能力

- 按需 search / explore / evidence，以及有真人明确授权的remember与持久收据。
- DSH会话级总指引和当前轮分析生命周期分离。
- DSH原生压缩对应真人原话的持久整理、来源去重、事务与失败恢复。
- 跨轮结构化事件、逐事实证据、语义重复分类、纠正与历史意义变化。
- 区分检索线索、关系候选和证据支持的关系，保留方向、复核与撤销历史。
- 可配置路径的Windows安装/更新脚本，默认不下载本地模型；已有数据库与模型配置保留。

## 安装与升级

需要Python3.10+（推荐3.11）、Node24.9+与DSH0.2.1-rc.5。下载安全源码包后按README注册本地link插件；模型/凭据在自己的DSH中配置。升级前备份，停后端与宿主，再Update并重启。schema6加法迁移前自动备份；退旧版需先生成兼容数据库副本，不能原地降级。

## 验证与限制

E阶段真实主模型与原Windows网页对有限虚构案例已验收；发布准备另用独立安装依赖、临时库与模拟模型验证。Python143通过/2既有Windows失败/1跳过；Node39通过/1跳过；SDK模拟回归4项及D/E事件集成1项通过。

不保证所有DSH版本、模型、系统或海量长期数据质量。旧D/B2跨来源全面语义去重、更多关系类型和长期规模仍有限；同模型复核不是独立事实核验。小样本平均延迟未显著改善，Token略增。每个非空整理批次通常额外使用主模型两次，可能产生费用。
