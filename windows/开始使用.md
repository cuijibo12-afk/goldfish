# Goldfish v0.8.0 Windows使用

完整步骤、隐私、验证范围和回滚见 [README](../README.md)。

1. 准备已有DSH0.2.1-rc.5、Python3.11和Node24.9+。
2. 将源码放在固定目录，在PowerShell运行Goldfish.ps1 Install，明确指定你自己的DSH可执行文件和DSH数据目录；示例见README。
3. 以后可双击Start.cmd、Chat.cmd；需要保存时说“请记住：……”，其他时候DSH自主选择是否查询。
4. /compact或原生自动压缩成功后，后台整理相应真人原话；会额外使用当前DSH主模型。
5. Stop.cmd仅停止本安装记录的金鱼后端。升级前停后端与DSH，用Update.cmd或明确路径的Update参数。
6. Uninstall.cmd移除插件，保留私人数据库、密钥、备份和DSH配置；源码与venv需自己确认后清理。

当前模式不要求金鱼自己的API Key，也不下载Ollama/BGE。Configure.cmd只核对/保存DSH路径，不代替DSH主模型设置。

默认数据在%LOCALAPPDATA%\GoldfishMemory。不要上传数据库、原话、日志、installation.json、能力文件或DSH认证信息。自定义数据目录时要同步设置插件的两个能力文件路径；自定义端口时同步serverUrl。
